# Objects.all()

## What is objects.all()?

objects.all() table ka sara data laata hai.

---

## Syntax

```python
Student.objects.all()
```

---

## Example

```python
students = Student.objects.all()

print(students)
```

---

## Flow

Database

↓

objects.all()

↓

All Records

↓

Browser
