# Templates Folder

## What is Templates Folder?

Templates Folder wo folder hota hai jahan hum HTML files rakhte hain.

Django isi folder se HTML pages load karta hai.

---

## Why We Use Templates Folder?

Website ke saare HTML pages ek hi jagah store karne ke liye.

Example

- home.html
- about.html
- contact.html
- login.html

---

## Folder Structure

project/

templates/

│

├── home.html

├── about.html

├── contact.html

└── login.html

---

## Flow

User

↓

View

↓

Templates Folder

↓

HTML File

↓

Browser

---

## Meri Language

Templates Folder HTML files ka ghar hota hai.

Jab user page open karta hai to Django isi folder se HTML file lekar browser me dikhata hai.
