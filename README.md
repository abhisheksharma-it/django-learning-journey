# Django Learning Journey

A structured, beginner-friendly Django learning repository that documents Django concepts step by step.

This repository currently contains 52 numbered lessons. The files are kept in their original learning sequence to preserve the learning history and make the progression easy to follow.

## Current Coverage

- Django project structure: `manage.py`, `settings.py`, `urls.py`, `views.py`, and `models.py`
- URL routing, dynamic URLs, redirects, request methods, and template URL tags
- Templates, template inheritance, static files, active links, and custom template filters
- Forms, form validation, user registration, login, and logout
- Models, migrations, QuerySets, CRUD operations, and ORM basics
- Sessions, cookies, messages, pagination, media files, file uploads, and email sending
- Function-based views, class-based views, middleware, signals, custom users, security, and caching

## Repository Style

- Files are numbered to preserve the learning sequence.
- Notes use simple explanations, short examples, and quick revision points.
- Hindi-English explanations are kept intentionally because they represent the original learning style.
- Existing lesson files are preserved as learning history.
