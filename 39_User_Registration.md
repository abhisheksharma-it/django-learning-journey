# User Registration in Django

## What is Registration?

Registration ka matlab naya user account banana.

---

## Information Required

- Username
- Email
- Password

---

## Flow

User

↓

Registration Form

↓

Validation

↓

Database

↓

Account Created

---

## Why We Use Registration?

- New User Create
- Store User Data
- Login Access

---

## Example

```python
User.objects.create_user()
```
