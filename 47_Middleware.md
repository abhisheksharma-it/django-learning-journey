# Middleware in Django

## What is Middleware?

Middleware Request aur Response ke beech ka software hota hai.

Ye request ko process karta hai.

---

## Why We Use Middleware?

- Authentication
- Security
- Logging
- Request Processing

---

## Flow

Browser

↓

Request

↓

Middleware

↓

View

↓

Response

↓

Middleware

↓

Browser

## Meri Language

Middleware Gatekeeper ki tarah kaam karta hai.
