# Order By in Django

## What is order_by()?

order_by() data ko sort karta hai.

---

## Ascending

```python
Student.objects.all().order_by("name")
```

---

## Descending

```python
Student.objects.all().order_by("-name")
```

---

## Why We Use?

- Name Wise
- Date Wise
- Price Wise
- ID Wise

---

## Meri Language

order_by() data ko sequence me arrange karta hai.

---

## One Line Revision

order_by() database data ko sort karta hai.
