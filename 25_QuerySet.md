# QuerySet in Django

## What is QuerySet?

QuerySet database se data retrieve karne ka Django ka tarika hai.

Ye objects ka collection hota hai.

---

## Why We Use QuerySet?

- Data Read
- Data Filter
- Data Search
- Data Sort

---

## Example

```python
Student.objects.all()
```

---

.all()

.filter()

.get()
