# Logout System in Django

## What is Logout?

Logout ka matlab user ko account se bahar nikalna.

---

## Why We Use Logout?

- Security
- Account Protection
- Session End

---

## Example

```python
from django.contrib.auth import logout
```

---

## Flow

User

↓

Logout Button

↓

Session End

↓

Login Page

---

## Meri Language

Logout user ka session khatam kar deta hai.

Uske baad protected pages open nahi hote.
