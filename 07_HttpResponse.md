# HttpResponse

## What is HttpResponse?

HttpResponse browser ko response bhejne ke liye use hota hai.

---

## Example

```python
from django.http import HttpResponse

def about(request):
    return HttpResponse("About Us")
```

Browser Output

About Us

---

## Meri Language

HttpResponse browser ko answer bhejne ka kaam karta hai.

---

## Interview Definition

HttpResponse is used to send a response from Django to the browser.
