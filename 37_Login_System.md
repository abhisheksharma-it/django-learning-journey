# Login System in Django

## What is Login?

Login ka matlab registered user ko website me enter karna.

User apna Username aur Password enter karta hai.

Agar details sahi hoti hain to login ho jata hai.

---

## Why We Use Login?

- User Authentication
- Secure Website
- Personal Dashboard
- User Account Access

---

## Login Flow

User

↓

Username + Password

↓

Authentication

↓

Login Success

↓

Home / Dashboard

---

## Example

```python
from django.contrib.auth import authenticate, login
```

---

Login ka matlab user ki identity verify karna.

Agar Username aur Password sahi ho to website access mil jata hai.
