# Form Validation

## What is Form Validation?

Validation ka matlab check karna ki user ne sahi data enter kiya hai ya nahi.

---

## Why We Use Validation?

- Empty Field Check
- Email Check
- Password Rules
- Wrong Data Rokna

---

## Example

```python
name = forms.CharField(required=True)
```

---

## Flow

User

↓

Enter Data

↓

Validation

↓

Correct → Save

Wrong → Error

---

## Meri Language

Validation data ko verify karti hai.

Galat data save nahi hone deti.

---

## One Line Revision

Validation user ke data ko check karti hai.
