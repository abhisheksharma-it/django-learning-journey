# Signals in Django

## What are Signals?

Signals automatically kisi event ke baad code chalate hain.

---

## Example

User Registration

↓

Signal

↓

Profile Automatically Create

---

## Why We Use Signals?

- Auto Email
- Auto Profile
- Auto Logging
- Auto Notification

---

## Common Signal

```python
post_save
```

---

## Flow

Object Save

↓

Signal

↓

Automatic Task

---

## Meri Language

Signals bina manually function call kiye automatic code chala dete hain.

---

## One Line Revision

Signals event hone ke baad automatically code execute karte hain.
