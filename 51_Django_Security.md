# Django Security

## What is Django Security?

Django me website ko common security problems se protect karne ke liye built-in security features hote hain.

---

## Important Security Features

### CSRF Protection

```html
{% csrf_token %}
```

Form ko CSRF attacks se protect karta hai.

---

### XSS Protection

Django templates user ke HTML input ko automatically escape karte hain.

---

### SQL Injection Protection

Django ORM queries ko safer way me handle karta hai.

---

### Password Hashing

Django password ko plain text me store nahi karta.

---

## Why We Use Security?

- User Data Protection
- Secure Login
- Safe Forms
- Database Protection

---
