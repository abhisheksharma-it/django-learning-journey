# Sessions and Cookies

## What are Cookies?

Cookies browser me chhoti information store karti hain.

Example

- Theme
- Language
- Remember Me

---

## What are Sessions?

Session server par user ki information store karta hai.

Example

- Login Status
- User ID
- Cart Data

---

## Difference

Cookies

↓

Browser

Sessions

↓

Server

---

## Why We Use?

- User Login
- Authentication
- Shopping Cart
- User Preferences

---

## Flow

User

↓

Login

↓

Session Created

↓

Cookie Sent

↓

Next Request

↓

User Recognized

---

## Meri Language

Cookie browser me data rakhti hai.

Session server par data rakhta hai.

Django login ke baad Session ka use karta hai.

---
