# Template Tags

## What are Template Tags?

Template Tags Django ke special tags hote hain.

Ye HTML ke andar Python jaisa kaam karte hain.

---

## Why We Use Template Tags?

- Static Files Load karne ke liye
- Loops chalane ke liye
- Conditions lagane ke liye
- Variables dikhane ke liye

---

## Common Template Tags

Load Static

```html
{% load static %}
```

Variable

```html
{{ name }}
```

If

```html
{% if user %}
```

For Loop

```html
{% for i in data %}
```

URL

```html
{% url 'home' %}
```

---

## Meri Language

Template Tags HTML ke andar Django ki special commands hoti hain.

Inki help se HTML page dynamic ban jata hai.
