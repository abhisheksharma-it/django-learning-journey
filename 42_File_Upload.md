# File Upload in Django

## What is File Upload?

User website par file upload kar sakta hai.

Example

- Resume
- PDF
- Image
- Video

---

## Why We Use?

- Profile Photo
- Documents
- Certificates
- Assignments

---

## HTML Example

```html
<form method="POST" enctype="multipart/form-data">

<input type="file" name="file">

</form>
```

---

## Flow

User

↓

Choose File

↓

Upload

↓

Server

↓

Database / Folder
