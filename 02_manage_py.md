# manage.py

## What is manage.py?

manage.py Django ka command center hota hai.

Iske through hum Django project ko control aur manage karte hain.

---

## Kya Kaam Karta Hai?

- Server start karta hai.
- Migration chalata hai.
- Superuser banata hai.
- Naya app create karta hai.
- Django ki important commands run karta hai.

---

## Important Commands

```bash
python manage.py runserver
```

Development server start karta hai.

```bash
python manage.py makemigrations
```

Migration file banata hai.

```bash
python manage.py migrate
```

Database me changes apply karta hai.

```bash
python manage.py createsuperuser
```

Admin account banata hai.

```bash
python manage.py startapp blog
```

Naya Django app create karta hai.

---

## Meri Language

manage.py Django project ka remote control hai.

Jitni bhi important commands chalti hain, wo isi file ke through chalti hain.

---

## Interview Definition

manage.py is a command-line utility used to manage and control a Django project.
